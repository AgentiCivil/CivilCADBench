# 任务：整套图纸重建——把一册施工图 PDF 复原成 CAD 工程

## 输入
- `input.pdf`：同一套桥梁施工图中的 **7 页**，每页 A3 横向（420 mm × 297 mm）。都是扫描/栅格化的图片，没有可提取的矢量和文字。图框和标题栏已去掉，不需要画。
- 页面清单：

| 页码 | 图号 | 图名 | 输出文件 |
|---|---|---|---|
| 1 | QL-29 | 支座布置图 | `output/page_01.dxf` |
| 2 | QL-30（第 1 页） | 支座一般构造 | `output/page_02.dxf` |
| 3 | QL-30（第 2 页） | 支座一般构造 | `output/page_03.dxf` |
| 4 | QL-30（第 3 页） | 支座一般构造 | `output/page_04.dxf` |
| 5 | QL-30（第 4 页） | 支座一般构造 | `output/page_05.dxf` |
| 6 | QL-32 | 防撞护栏 | `output/page_06.dxf` |
| 7 | QL-33 | 人行道外侧栏杆构造图 | `output/page_07.dxf` |

## 输出
在 `output/` 目录下，**每页一个 DXF**（DXF R2018），文件名按上表的"输出文件"列，例如 `output/page_01.dxf`。每个文件都要尽可能完整、准确地还原该页全部内容，并且是可继续编辑的 CAD 工程。

这是同一套图：请保持**全册一致**——统一的图层规范、文字样式、标注样式；同一构件在不同页上的尺寸、编号要一致。页与页之间内容相似时，可以复用你自己的程序或图块，不必每页从零开始。

### 坐标约定（每页都必须遵守）
- 单位为毫米，按**图纸纸面尺寸**绘制（1 个绘图单位 = 纸面上 1 mm）。
- 原点在该页图纸**左下角**，x 向右、y 向上。整页在 (0,0)–(420,297) 范围内。

### 图层规范（必须遵守）
所有图元只能放在下面 9 个图层上，图层名必须一字不差：

| 图层名 | 内容 |
|---|---|
| `S-结构轮廓` | 构件可见轮廓线（混凝土、钢构件外形） |
| `S-钢筋` | 钢筋、预应力钢束及其断面点（钢筋图中的钢筋线/圆点） |
| `S-虚线` | 不可见轮廓（虚线） |
| `S-中心线` | 中心线、轴线（点划线） |
| `S-填充` | 材料图例填充（HATCH） |
| `A-尺寸标注` | 尺寸标注（DIMENSION 实体及手绘尺寸线） |
| `A-文字` | 所有文字：图名、说明、表格内文字、钢筋编号 |
| `A-符号` | 标高符号、引出线、剖切符号、索引圈、图名下划线等注释图形 |
| `A-表格` | 表格的框线与分隔线 |

### 图元要求
- 尺寸标注用 `DIMENSION` 实体，显示的数值与图中一致（可用文字替代 `text=`）。用 ezdxf 时记得调用 `.render()`。
- 文字用 `TEXT` / `MTEXT`，内容与图中一致（含中文）。
- 填充用 `HATCH`；虚线、点划线使用相应线型（如 `DASHED`、`CENTER`）；圆、圆弧用 `CIRCLE` / `ARC`。

## 可用环境
- Python：`{PYTHON}`（已装 ezdxf、pymupdf、opencv-python-headless、scikit-image、numpy、scipy、pillow、matplotlib）。
- 预览工具：`{PYTHON} tools/render_preview.py output/page_01.dxf preview.png --extents 0 0 420 297 --dpi 150`，出图方式与输入 PDF 相同。
