# 任务：根据图纸 PDF 重建 CAD 工程文件

## 输入
- `input.pdf`：一页图纸，A3 横向（420 mm × 297 mm）。它是扫描/栅格化的图片，没有可提取的矢量和文字。
- 图纸内容：一张桥梁施工图（可能是一般构造图或钢筋构造图：多个视图、尺寸标注、钢筋编号、标高符号、表格、说明文字）。图框和标题栏已去掉，不需要画。

## 输出
在当前目录写出 **`output.dxf`**（DXF R2018，推荐用 Python `ezdxf` 生成），尽可能完整、准确地还原图纸上的全部内容，并且做成**可继续编辑的 CAD 工程**，而不是一堆散线。

### 坐标约定（必须遵守）
- 单位为毫米，按**图纸纸面尺寸**绘制（1 个绘图单位 = 纸面上 1 mm），不要换算成实际构件尺寸。
- 原点在图纸**左下角**，x 向右、y 向上。PDF 中某点距页面左边 a mm、距下边 b mm，它在 DXF 中的坐标就是 (a, b)。整张图在 (0,0)–(420,297) 范围内。

### 图层规范（必须遵守）
所有图元只能放在下面 9 个图层上，图层名必须一字不差：

| 图层名 | 内容 |
|---|---|
| `S-结构轮廓` | 构件可见轮廓线（混凝土、钢构件外形） |
| `S-钢筋` | 钢筋、预应力钢束及其断面点（钢筋图中的钢筋线/圆点） |
| `S-虚线` | 不可见轮廓（虚线） |
| `S-中心线` | 中心线、轴线（点划线） |
| `S-填充` | 材料图例填充（HATCH） |
| `A-尺寸标注` | 尺寸标注（DIMENSION 实体及手绘尺寸线） |
| `A-文字` | 所有文字：图名、说明、表格内文字、钢筋编号 |
| `A-符号` | 标高符号、引出线、剖切符号、索引圈、图名下划线等注释图形 |
| `A-表格` | 表格的框线与分隔线 |

### 图元要求
- 尺寸标注用 `DIMENSION` 实体（线性/对齐/半径等），显示的数值与图中一致（可用文字替代 `text=`）。用 ezdxf 时记得调用 `.render()`。
- 文字用 `TEXT` / `MTEXT`，内容与图中一致（含中文）。字高、位置尽量接近原图。
- 填充用 `HATCH`；虚线、点划线使用相应线型（如 `DASHED`、`CENTER`）。
- 圆、圆弧用 `CIRCLE` / `ARC`，不要用折线逼近。

## 可用环境
- Python：`{PYTHON}`（已装 ezdxf、pymupdf、opencv-python-headless、scikit-image、numpy、scipy、pillow、matplotlib）。
- 预览工具：`{PYTHON} tools/render_preview.py output.dxf preview.png --extents 0 0 420 297 --dpi 150`。它会用和输入 PDF 相同的出图方式（黑白、按图层线宽）渲染你的 DXF，方便和输入对比、自我修正。
- 你可以把 PDF 转成 PNG，裁剪、放大局部后查看图片。

## 规则
- 只能使用当前目录里的文件。**不要**在本机其他位置搜索或读取任何 DWG/DXF/PDF 图纸或项目资料，也不要从网上下载这张图纸。运行日志会被审计，违规按作弊处理。
- 完成后在当前目录写一份简短的 `NOTES.md`：做法、各图层放了什么、你知道的遗漏或不确定之处。
