# 任务：套图补页——按新参数改出同一套图中缺失的一页

## 背景
设计院出施工图时，同类构件的图（如 0 号桥台与 3 号桥台、不同宽度的搭板）通常先画好一页，再按各自的设计参数改出其他页。
现在这套图里缺了一页，你要以参考页的 CAD 为底稿，按给定的新参数改出这一页。

## 输入（都在 `ref/` 目录）
- `ref/sibling.dxf`：参考页的**可编辑 CAD 工程**（已按下方图层规范分层，坐标单位为纸面 mm）。
- `ref/sibling.pdf`：参考页的出图（栅格图片）。
- `ref/context.pdf`：本套图中其他相关页的出图（栅格图片，多页），页码与图名见 `ref/context_index.md`。可从中查找需要的尺寸、标高、数量等信息。

## 要画的这一页
图号 QL-23~24，第 2 页（共 4 页）：**齿板施工图（齿块立面），适用于中腹板处钢束 T1**（参考页 ref/sibling.dxf 适用于边腹板处钢束 T1a）。

请按中腹板钢束 T1 的构造（可在预应力钢束构造图中查找）更新图名、说明以及受影响的尺寸。

## 输出
在当前目录写出 **`output.dxf`**（DXF R2018），即缺失页的完整 CAD 工程：
- 按新参数更新所有受影响的内容：几何尺寸、尺寸标注数值、标高、钢筋根数/长度/编号、表格数值、说明文字等。未受影响的部分保持与参考页一致。
- 坐标约定、图层规范与参考页相同：单位为纸面 mm，原点在图纸左下角，整张图在 (0,0)–(420,297) 内；图面布置可参照参考页。
- 所有图元只能放在下面 9 个图层上：

| 图层名 | 内容 |
|---|---|
| `S-结构轮廓` | 构件可见轮廓线（混凝土、钢构件外形） |
| `S-钢筋` | 钢筋、预应力钢束及其断面点（钢筋图中的钢筋线/圆点） |
| `S-虚线` | 不可见轮廓（虚线） |
| `S-中心线` | 中心线、轴线（点划线） |
| `S-填充` | 材料图例填充（HATCH） |
| `A-尺寸标注` | 尺寸标注（DIMENSION 实体及手绘尺寸线） |
| `A-文字` | 所有文字：图名、说明、表格内文字、钢筋编号 |
| `A-符号` | 标高符号、引出线、剖切符号、索引圈、图名下划线等注释图形 |
| `A-表格` | 表格的框线与分隔线 |

- 尺寸标注用 `DIMENSION` 实体（数值与新参数一致），文字用 `TEXT`/`MTEXT`，填充用 `HATCH`，虚线/点划线用相应线型。

## 可用环境
- Python：`{PYTHON}`（已装 ezdxf、pymupdf、opencv-python-headless、scikit-image、numpy、scipy、pillow、matplotlib）。
- 预览工具：`{PYTHON} tools/render_preview.py output.dxf preview.png --extents 0 0 420 297 --dpi 150`，出图方式与参考页 PDF 相同。

## 规则
- 只能使用当前目录里的文件。**不要**在本机其他位置搜索或读取任何 DWG/DXF/PDF 图纸或项目资料，也不要上网查找。运行日志会被审计，违规按作弊处理。
- 完成后写一份 `NOTES.md`：哪些内容按参数改了、每个改动值的推导依据（来自哪一页或怎么算的）、你无法确定的值。
